DATABASE TABLES CREATED
=======================

1. phone_number_provider_configs
   - Provider configuration per tenant
   - Supports: Twilio, Telnyx, Plivo, SignalWire, Exotel, SIP
   - Stores API credentials, webhooks, SIP configuration
   - Status: active, inactive, error, suspended

2. phone_numbers
   - Core phone number storage
   - E164 format validation
   - Capabilities: voice, SMS, MMS, WhatsApp
   - Status: provisioning, active, inactive, suspended, released
   - Routing modes: direct, intent
   - Recording policies: always_record, never_record, consent_required, country_based, workflow_based, agent_based
   - Business hours integration
   - Spam protection and emergency calling flags
   - Multi-tenant isolation

3. phone_number_assignments
   - Assign numbers to workflows, agent groups, router agents, default agents
   - Priority-based assignment
   - Active/inactive toggle
   - Assignment types: workflow, agent_group, router_agent, default_agent

4. phone_number_usage
   - Daily usage tracking
   - Inbound/outbound calls, minutes, costs
   - Missed, failed, busy call tracking
   - Date-based aggregation

5. phone_number_spam_list
   - Blacklist/whitelist management
   - Spam score tracking
   - Reason documentation

6. phone_number_audit_logs
   - Complete audit trail
   - Actions: purchased, released, assigned, unassigned, activated, suspended, configuration_updated, webhook_received, call_initiated, call_completed, call_failed, recording_started, recording_stopped, spam_detected
   - Actor types: system, user, webhook, scheduler
   - Status: success, failed, warning

7. phone_calls
   - Call record storage
   - Call types: manual, workflow, campaign, scheduled, api, retry
   - Directions: inbound, outbound
   - Statuses: initiated, ringing, active, completed, failed, missed, busy
   - Duration and cost tracking
   - Recording URL storage
